## 决策主体与选题摘要

本报告面向 **个人投资者（散户）**，帮助他们在 A 股 38 家上市银行中，基于市盈率（估值）和股息率（回报）两个核心维度，识别出真正"便宜且分红慷慨"的银行股，避免买入"估值虚低、分红不可持续"的价值陷阱。

核心发现：股份制银行（兴业、光大）在 PE 和股息率上全面领先国有大行；2023 年分红新规后银行间分化加剧——盈利能力强的银行主动提高分红（招商 +32%），利润承压的银行即使面对监管也难以跟进。
